About the Project

Personalized Career Recommendation System Using Machine Learning

Project Overview

This is an intelligent career guidance system developed as an MCA Major Project. It uses an XGBoost machine learning model trained on 7,500 student records with 75 unique career paths to predict the most suitable career for each individual.

The system analyses a student's academic background, technical skills, soft skills, interests, personality traits, and career goals to generate personalized top-5 career recommendations with confidence scores.
