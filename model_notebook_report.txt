1. EXECUTIVE SUMMARY & NOTEBOOK OVERVIEW
====================================================================================================
The model training notebook ('notebook.ipynb' / 'Career_Recommendation_ML_Training_EDA_SHAP.ipynb')
implements an end-to-end, scientifically validated machine learning workflow designed to predict 
career compatibility for Indian school students across 1,203 professional occupations.

Traditional career guidance relies heavily on subjective intuition or simplistic heuristic rules. 
This notebook addresses these shortcomings by formulating career recommendation as a supervised,
gradient-boosted classification and ranking task. The training pipeline processes 10,000 student 
assessment profiles, 1,206 career knowledge profiles, and 50,000 historical compatibility interaction
records.

5. HIGH-DIMENSIONAL FEATURE ENGINEERING PIPELINE (19 FEATURES)
====================================================================================================
The feature pipeline constructs a rich, non-linear representation of student-career alignment:

1. COGNITIVE ABILITY MATCHING COMPONENT (8 PAIRS):
   Computes mean absolute divergence between student demonstrated aptitude and career required benchmark:
   ability_match_component = mean( 100.0 - | student_ability_i - career_required_ability_i | )
   Evaluated across: Mathematical, Logical, Scientific, Problem Solving, Analytical, Communication,
   Creativity, and Digital Ability.

2. DYNAMIC INTEREST MATCHING COMPONENT (10 PAIRS WITH 1.5x BOOST):
   Computes weighted divergence across disciplinary interests (Technology, Engineering, Healthcare,
   Business, Finance, Arts, Design, Research, Environment, Agriculture). The top 3 student interests
   receive a 1.5x boost multiplier to elevate alignment with declared student passion:
   interest_match_component = ( sum( weight_j * (100 - |student_int_j - career_int_j|) ) / sum(weights) )

3. COMPOSITE & SYNERGY FORMULATIONS:
   * composite_alignment_index = 0.45 * Ability + 0.35 * Interest + 0.10 * Academic + 0.10 * Learning
   * ability_interest_synergy   = (Ability * Interest) / 100.0
   * ability_interest_gap       = | Ability - Interest |
   * min_core_match             = min( Ability, Interest )
   * max_core_match             = max( Ability, Interest )
   * harmonic_core_match        = 2.0 * (Ability * Interest) / (Ability + Interest + 1e-5)
   * geometric_core_synergy     = sqrt( max(0.0, Ability * Interest) )
   * holistic_synergy           = ( Ability * Interest * Academic * Learning ) ^ 0.25

4. DEMOGRAPHIC & CATEGORICAL ENCODING:
   * Numerical : age, class, academic_match_component, learning_match_component.
   * Categorical: career_name, career_domain, career_subdomain, career_cluster, stream.
   Processed via scikit-learn 'ColumnTransformer' utilizing 'OrdinalEncoder' with handle_unknown='use_encoded_value'.
